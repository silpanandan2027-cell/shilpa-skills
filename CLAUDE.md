# Working in this repo

For any website, landing page, web app, UI or HTML page work, always follow the `web-design` skill
(`skills/web-design/SKILL.md`): research with Refero and Firecrawl, use a DESIGN.md, build with React Bits,
GSAP and Anime.js, check docs with Context7, review with Impeccable, and test in Chrome DevTools.

The plugins (Impeccable, Refero) and MCP servers (Chrome DevTools, Context7, Firecrawl, shadcn for React Bits)
are switched on for this repo in `.claude/settings.json` and `.mcp.json`. `install.sh` / `install.ps1`
switch them on for every project on your computer.

For any video work (edit, cut, caption, transcribe, download, render, motion graphics), follow the `video-editor` skill
(`skills/video-editor/SKILL.md`): FFmpeg, yt-dlp, Whisper (whisper.cpp), HyperFrames and Remotion. The HyperFrames plugin is
switched on in `.claude/settings.json`; cloud sessions install the tools from the environment's setup script.

For voiceovers and voice clones, AI images and video, SEO, questions across documents, dictation, tasks and boards,
booking links, a customer inbox, or screen recordings, follow the `free-apps` skill (`skills/free-apps/SKILL.md`):
use the nine free apps (VoiceStudio, Open Higgsfield, OpenSEO, WeKnora, OpenWhispr, OpenProject, Cal.diy, Chatwoot, Cap),
not the paid ones. `apps/free-apps.sh` (Windows: `apps/free-apps.ps1`) installs, starts, stops and checks them.
