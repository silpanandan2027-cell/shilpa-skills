# Landing page example

A landing page for these skills, built with the web design stack (`skills/web-design`):
Runway's DESIGN.md, React Bits (`BlurText`, `CountUp`), GSAP ScrollTrigger, Anime.js, and checked with Impeccable.

```bash
cd examples/landing-page
npm install
npm run dev      # open the address it prints
npm run build    # one self-contained file in dist/index.html
```

React Bits components were added with `npx shadcn@latest add @react-bits/BlurText-TS-CSS @react-bits/CountUp-TS-CSS`
(the registry is set in `components.json`).
